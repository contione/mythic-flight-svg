# 云端奇航

纯 SVG 原创矢量插画与无依赖静态 HTML 项目：孙悟空驾驶大型飞机，鹈鹕在机翼上骑自行车，双翼托起秦始皇骑着的北极熊，秦始皇使用电动螺丝刀工作。鹈鹕喊出糖果题答案 **29**。

- 在线访问：https://contione.github.io/mythic-flight-svg/
- 公开仓库：https://github.com/contione/mythic-flight-svg
- `scene.svg`：1600 × 1000 可无限缩放矢量原图，无内嵌位图与外部资源。
- `index.html`：画作展示、下载、完整题目及推导。
- `styles.css`：桌面与手机响应式样式。

## 本地运行

在此目录执行 `python -m http.server 4189`，打开 http://localhost:4189 。也可以直接打开 `index.html`。

## 数学依据

按不筛选、不放回取糖计算。不存在目标配对时，圆形苹果和五角星桃子不能同时出现，五角星苹果和圆形桃子也不能同时出现。最多可取 `max(7,6) + max(7,9) + 8 + 4 = 28` 颗而失败。这个上限可达到：7颗圆形苹果、9颗圆形桃子、12颗西瓜。因此保证成功的最小数量是29。
